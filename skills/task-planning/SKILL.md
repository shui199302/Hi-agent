# 任务规划

## 工作流程

1. 提出变更前检查当前环境、仓库说明、接口、测试和部署约束。
2. 明确目标和可观测的成功标准，并区分已确认事实、用户选择和假设。
3. 与用户解决高影响的不确定项；对次要缺口选择安全默认值并记录。
4. 按行为和子系统描述实现方案，包括公共接口、数据流、状态转换和兼容性。
5. 按需覆盖失败模式、安全边界、数据迁移、回滚、可观测性和发布流程。
6. 定义能够证明目标达成的测试与验收场景。

计划应保持精炼，但不得遗留影响实施的未决事项。用户仅要求计划时，不得执行写入或变更操作。
